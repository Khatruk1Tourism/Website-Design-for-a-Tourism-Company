# Khatruk Travel & Tourism — خاطرك للسفريات والسياحة

موقع ثابت (HTML / CSS / JavaScript) باللغة العربية واتجاه RTL، بهوية بصرية
كحلي غامق + ذهبي عتيق + أبيض، واسم تجاري ثنائي اللغة بارز في كل صفحة.
يتكوّن الموقع من **35 صفحة**: الصفحة الرئيسية، دليل الخدمات، **14 صفحة خدمة**،
و**19 صفحة داخلية** (من نحن، السياسات، الأدوات التفاعلية، التواصل…).

## المعاينة

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```powershell
python -m http.server 8123
# ثم افتح: http://127.0.0.1:8123/index.html
```

## حدود الموقع الثابت

لا توجد قاعدة بيانات أو خادم خلفي. لذلك:

- النماذج لا ترسل بريداً تلقائياً؛ تجهّز رسالة واتساب لتأكيد الإرسال يدوياً.
- صفحة التتبع لا تعرض حالة مباشرة من نظام داخلي؛ تجهّز استعلاماً رسمياً
  لمتابعة الفريق، وهذا مذكور صراحةً في الصفحة.
- نتائج فحص التأشيرات والدول استرشادية ومصحوبة بإخلاء مسؤولية.
- تُحفظ تفضيلات الزائر محلياً في `localStorage` بالمفاتيح:
  `khatruk_newsletter` و`khatruk_cookie_consent` و`khatruk_notification_prefs`.
